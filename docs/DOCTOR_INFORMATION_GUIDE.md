## 🗂️ Actualización del Schema de Prisma

Basándome en esto, el schema debería incluir:

```prisma
model Doctor {
  id           Int        @id @default(autoincrement())
  
  // Relación con User (info básica: nombre, email, password, rol)
  userId       Int        @unique
  user         User       @relation(fields: [userId], references: [id])
  
  // FASE 1 - MVP
  specialityId Int
  speciality   Speciality @relation(fields: [specialityId], references: [id])
  license      String?    // MPPS-12345
  biography    String?    // Biografía pública
  photo        String?    // URL de la foto
  
  // FASE 2 - Gestión Operativa
  ci           String?    @unique // Cédula
  rif          String?    // RIF
  cmca         String?    // Colegio Médico
  birthDate    DateTime?
  gender       String?
  nationality  String?
  
  // Organizacional
  departmentId Int?       // Relación a Departamento
  supervisorId Int?       // Doctor que es su jefe
  supervisor   Doctor?    @relation("DoctorSupervisor", fields: [supervisorId], references: [id])
  subordinates Doctor[]   @relation("DoctorSupervisor")
  position     String?    // Jefe de Servicio, Adjunto, etc.
  contractType String?    // Planta, Honorarios, etc.
  hireDate     DateTime?
  status       String?    @default("ACTIVE") // ACTIVE, INACTIVE, VACATION
  
  // Operativa
  officeNumber String?    // Consultorio 305
  consultationDuration Int? @default(30) // minutos
  maxPatientsPerDay    Int? @default(16)
  emergency    Boolean?   @default(false)
  
  // FASE 3 - Completa
  university   String?
  graduationYear Int?
  subspecialties String? // JSON o texto
  certifications String? // JSON o texto
  languages    String?   // Español, Inglés
  consultationFee Decimal? // Tarifa
  commissionRate  Decimal? // Porcentaje
  
  // Timestamps
  createdAt    DateTime   @default(now())
  updatedAt    DateTime   @updatedAt
  
  // Relaciones
  schedule     Schedule[]
  appointments Appointment[]
}
```
